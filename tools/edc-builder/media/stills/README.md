Generated or photographed product images go here, one per product id, and get
listed in `../manifest.js`:

```js
window.EDC_MEDIA = { 'u_a1b2c3': 'stills/u_a1b2c3.png' };
```

Cut the background out, shoot or generate square-on, and light from the top
left. Those three are what decide whether an image sits with the drawings or
floats over them looking like a sticker.

The app's **Image brief** button (Build tab, under Your products) writes a
prompt that already asks for all three.
